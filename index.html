  • v3.3.0 - Multi-nodule Workflow
    Current Version
    • Multiple nodules: Track separate Nodule IDs under one Patient ID and manage each one in the worklist.

    • Clearer results: Added explicit interval and change labels, including total interval and total change.
    • Terminology: Renamed Core volume to Solid core while retaining VDTcore.
  • v3.2.4 - VDT Color Standard
    • Consistent clinical colors: Restored the established red, orange, and blue VDT color codes across the table, reports, totals, and worklist.
  • v3.2.3 - Baseline & Icon
    • One-click Baseline: Restored the radio selector with its full name and kept label editing frictionless.
    • App icon: Reframed the mark around simplified lungs, a solid nodule, and its dashed future growth boundary.
  • v3.2.2 - Table Clarity
    • Volume alignment: Removed the in-table “(new)” badge so measurements remain precisely centered; copied reports still retain it.
    • Baseline workflow: Removed the redundant BL radio column; use the full “Baseline” screening-round anchor instead.
  • v3.2 - Clinical Interface
    • Identity: Renamed to VDT Calculator across the app and install metadata.
    • Visual system: Introduced a restrained medical palette, clearer hierarchy, and denser data presentation.
    • Language: Simplified controls and clarified backup, restore, screening-round, and workflow actions.
  • v3.1 - Expert Read Workflow
    • New nodules: The absent prior volume stays blank, while the first measured volume is marked “(new)”.
    • Copy report: Total VDT appears only when at least two comparable regular VDT intervals exist.
    • Screening labels: Enter any one standard round as an anchor to infer adjacent annual and repeat-3m labels.
  • v3.0 - Reliability & App Experience
    • PWA: New install icon and reliable offline app shell.
    • Data quality: Strict date validation and safer CSV round-tripping.
    • Privacy & safety: User-entered labels, notes, and IDs are rendered safely.
  • v2.12 - Data Migration (Import/Export)
    • Export CSV: Now generates a robust backup containing ALL patients, notes, settings, and scan histories.
    • Import CSV: New feature to seamlessly restore previously exported data. Perfect for migrating from Edge to Chrome.
  • v2.11.2 - Naming & Slot Logic Updates
    • Smart Slot Logic: First scan in annual windows takes the "Annual" slot, and subsequent ones are marked relative (e.g. +3m) preventing "1st 3m" jumps.
    • Smooth Typing: Keyboard Enter now intelligently focuses the next input without breaking flow.
    • Copy Report Fix: Fixed N/A Total VDT error when using "New Nodule".
  • v2.10 - Smart Biennial & Chart fixes
    • Smart Biennial Logic: Correctly labels "Biennial" scans.
    • Chart Labels: Direct on-chart data labels display Volume & VDT.
