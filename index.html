  • v3.4.0 - Total VDT projection
    Current Version
    • Chart controls now stay beside the chart.
    • Projection automatically opens in log scale and displays +3m, +6m, +9m, and +12m (1y) together.
    • A dashed Total VDT trend is labelled once and the selected projection continues that same trajectory.
  • v3.3.9 - Sequential screening labels and slide-ready reports
    Current Version
    • The first observed scan in a newly inferred stage establishes its routine label before any +3m repeat is assigned.
    • Short-term repeat labels remain +3m, +6m, and +9m.
    • Automatic slide width: Two to four scan labels align with their image centres and interval VDT values align with the boundaries between images.
    • Compact editable report: PowerPoint-compatible 0.01 in cell padding keeps pasted reports short without forcing a row height.
    • Faster patient lookup: Press Enter after a unique partial Patient ID to load its full saved record; ambiguous matches open in the Worklist.
  • v3.3.8 - Automatic Nodule Status
    • Automatic New Nodule: Each volume type is recognized when its first measurement follows an earlier dated scan, so VDTmax no longer requires a checkbox.
    • Resolved: A blank volume on the latest scan is labelled (resolved) when that volume type was measured previously.
  • v3.3.7 - Cleaner Copy Report
    • Concise Total VDT: Copy Report keeps the Total VDT value but omits redundant total interval and total change details.
  • v3.3.6 - New-nodule Appearance Detection
    • Correct VDTmax interval: A new nodule is anchored to the first scan containing a valid volume, using the immediately preceding scan date for VDTmax.
    • Accurate reports: Scans before the first appearance stay blank, while subsequent intervals use regular VDT.
  • v3.3.5 - Compact Full-width Table
    • Single-page width: Narrower columns keep the complete measurement and VDT table visible without horizontal clipping on a standard app window.
    • Compact interval details: Interval and volume change now use the concise format 742d｜+210%.
  • v3.3.4 - Faster Unsaved Nodule Entry
    • No Patient ID required: Add, switch, and remove nodules during an unsaved session; Reset clears the whole session.
    • Cleaner location field: The example is shown inside the optional input without a separate label.
  • v3.3.3 - Compact Two-scan Report
    • Two-scan layout: When only one VDT interval exists, Copy Report places the VDT directly between the two volumes instead of adding a separate row.
  • v3.3.2 - Hierarchical Screening Menu
    • Two-level labels: Choose a routine screening round directly or hover to select its +3m, +6m, or +9m repeat.
    • Simpler table: Removed the redundant Baseline radio column.
    • Nodule controls: Location is explicitly optional, and the active nodule can be deleted when another nodule remains.
  • v3.3.1 - Nodule Switching
    • One clean label control: Replaced the duplicate label inputs with a single screening-round selector.
    • Compact VDT context: Shows days and volume change without repetitive labels.
    • Fast multi-nodule entry: Switch between #1, #2, and later nodules; Add nodule keeps scan dates and clears measurements.
    • Nodule location: Save identifiers such as RUL #133 and see them in the Worklist.
